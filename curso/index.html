La skill “Creador de Webs”

Tu diseñador web dentro de Claude
  1. Preparate una sola vezPlan Pro de Claude, la extensión Claude in Chrome instalada y tu sesión de GitHub abierta en Chrome. Lo ves en la clase 3.
  2. Copiá la skillTocá el botón rojo “Copiar skill”.
  3. Pegala en ClaudeCreá un Proyecto, tocá “Instrucciones” y pegala. (O subí el ZIP en Personalizar › Skills › “+” › “Crear skill” › “Subir una skill”.)
  4. Escribí “Quiero crear mi web”Respondé las preguntas, subí tus fotos y elegí los cambios que quieras.
  5. Decí “sí” y listoClaude publica tu web en tu GitHub desde tu Chrome. Vos solo aceptás los permisos.
